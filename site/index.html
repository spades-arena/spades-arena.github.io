Installing on Android

  1. Tap Download APK and open the file when it finishes.
  2. If asked, allow your browser to install unknown apps.
  3. Tap Install. If Play Protect warns you, choose Install anyway.

Installing on Windows

If you see “Windows protected your PC”, click More info and then Run anyway.

Installing on Mac

Open the .dmg and drag Spades Royale into Applications. The first time, right-click the app and choose Open. If macOS says the app is damaged, open Terminal and run xattr -cr "/Applications/Spades Royale.app".
